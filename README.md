# Muslim Medical Mission

A redesign of [mmm.org.pk](https://mmm.org.pk), built as a static Next.js site and
deployable to Cloudflare.

## Running it

```bash
npm install
npm run dev        # development server on :3000
npm run build      # static export into out/
npm start          # serve the built output on :4321
```

## Deploying to Cloudflare

`next.config.mjs` sets `output: "export"`, so the build produces a plain static
site in `out/`. Nothing needs a Node runtime at request time.

**Workers (recommended, config already in `wrangler.jsonc`):**

```bash
npx wrangler login
npm run deploy
```

**Pages (dashboard or CI):**

- Build command: `npm run build`
- Output directory: `out`

`public/_headers` sets long lived caching for `/media/*` and `/_next/static/*`
plus a few security headers. Cloudflare picks it up automatically on both
Workers static assets and Pages.

## How it is put together

```
src/
  app/                  routes, one folder per page
    what-we-do/[slug]/  a page per programme, generated from data
  components/           header, hero, cards, reveal and count animations
    home/               the homepage sections
  data/
    site.ts             all copy, navigation, programmes, giving tiers
    gallery.ts          generated from public/media, see below
    search.ts           the index behind the header search
  lib/inView.ts         the shared scroll trigger
public/media/           photography, organised by programme
```

**Content lives in `src/data/site.ts`.** Programme text, unit costs, bank
details, navigation and field reports are all there, so copy changes do not
require touching components.

**Photography is organised by where it was taken**, which matters here: the
`disaster/` folder is the Pakistan flood response, and `medical/`, `ration/`,
`gaza-water/`, `gaza-food/` and `gaza-winter/` are all Gaza. Nothing is
captioned as a place it did not come from. Programmes with no matching
photograph (Save Vision, prison healthcare, paramedic training) deliberately
render a drawn panel rather than borrowing an unrelated picture.

`src/data/gallery.ts` is generated by listing `public/media`. If you add or
remove photographs, regenerate it or edit it by hand to match.

## Design notes

- Brand colours are sampled from the logo: blue `#0092DD`, magenta `#DD127B`.
  Navy carries the structure, cyan `#40D9F1` is the accent on dark grounds.
- The hero is sized to `100svh` so the whole of it is visible on landing,
  without scrolling, on both desktop and mobile.
- Section headings have no eyebrow or kicker label above them anywhere on the
  site. Hierarchy is carried by the hairline rule and the two column split.
- Scroll animations use a single rAF throttled listener in `lib/inView.ts`
  rather than IntersectionObserver, because a fast scroll or an anchor jump can
  carry an element past the viewport before an observer callback is delivered,
  leaving it invisible for good.
- Everything respects `prefers-reduced-motion`.
